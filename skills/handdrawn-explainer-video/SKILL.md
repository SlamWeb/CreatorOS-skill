# 手绘科普成片

输入为定稿旁白、同版配音 WAV、SRT 和实际语音时间轨。SRT 用于片内字幕，词级时间用于安排动作和切点，配音决定片长。对照旁白和时间轨核对输入版本。需要改动表述时，先在文案阶段改定稿和对应音频。

以暖纸底、稳定的笔压墨线、少量强调色和清晰的剪影为默认视觉。用动作、接触和可见的状态变化讲清内容。画面只放内容需要的字和字幕。镜头数量、角色、视觉比喻、构图、节奏和转场由本集内容决定。动作质感与审片要点见 [风格和审片](references/style-and-review.md)。

1. **分镜。** 按真实口播划分观众需要依次理解的变化。每镜在可编辑工程里记录对应的音轨位置、主体动作和镜头衔接。为本集找一个能贯穿或强化主题的视觉处理。
2. **样片。** 先预览最难的动作或交接，调整后做出从片头到片尾、带实际口播及字幕的可播放样片。可把 [Canvas 工具](references/canvas.md) 作为起点，也可选适合本集的可编辑制作方式。
3. **审改两轮。** 每轮新开一个空白上下文的 judge，由制作 agent 提供当轮完整样片、定稿旁白和风格及审片要点。第一轮看讲述和关键动作，修改并导出修订样片。第二轮把修订样片交给另一位独立 judge 按高端商用动画和获奖短片的标准精修。逐轮保存 judge 的时码反馈、对应样片和处理结果。两位 judge 都根据实际成片取证，由制作 agent 修改工程。
4. **交付。** 修完第二轮再渲染最终 MP4，核对编码后片长、字幕入出点和音画同步，抽看修改后的连续动作。交付 MP4 和可重渲染的工程，包含音频、字幕、分镜、场景源文件、素材与重建命令。每集使用自己的输出目录。
